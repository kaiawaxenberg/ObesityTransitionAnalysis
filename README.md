## Purpose and Important Information
This repository contains code for data preparation, statistical analysis, and visualisation to accompany the manuscript "­­­Socioeconomic gradients in BMI: ​A cross-country analysis of the obesity transition," prepared as part of my PhD research at the University of Edinburgh.

Access to data from the EHIS and HPACC are governed by dataset-specific access applications. Without access to those data sources, the analysis cannot be reproduced. The scripts included here, though not executable without the data, aim to showcase additional methodological detail beyond the description provided in the written manuscript.
