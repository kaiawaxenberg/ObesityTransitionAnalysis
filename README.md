# Obesity Transition Analysis
This repository contains code for data preparation, statistical analysis, and visualisation to accompany the manuscript "­­­Socioeconomic gradients in BMI: ​A cross-country analysis of the obesity transition"

Access to data from the EHIS and HPACC are governed by separate agreements. Therefore, the analysis cannot be reproduced from this repository without separately accessing the necessary data sources. The scripts included here provide additional detail beyond the methodological description provided in the manuscript.
